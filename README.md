# الموسوعة العُمانية الرقمية الذكية — Omani Digital Encyclopedia AI

منصة موسوعية عربية رقمية متكاملة (RTL) لتوثيق وبحث المعرفة المتعلقة بسلطنة عُمان (التاريخ، الحضارة، المحافظات والولايات، الجغرافيا، البحار والجزر، القلاع والحصون، الأعلام والشخصيات، السلاطين والدولة البوسعيدية، التراث والأفلاج، الفنون والحرف، الأدب واللغة، العلوم والتعليم، الاقتصاد والدقم، البيئة والحياة الفطرية، السياحة، المؤسسات الوطنية، ورؤية عُمان 2040).

> **تنويه الهوية:** هذا المشروع منصة معرفية وبحثية ثقافية ذات هوية أصلية مستقلة، ولا يدّعي أنه موقع حكومي رسمي. جميع المقالات مصاغة بأسلوب موسوعي أصلي مع توثيق المصادر والروابط المرجعية وحفظ حقوق الجهات الناشرة.

---

## 1. تشغيل المشروع محلياً (Local Development)

المشروع مبني باستخدام **Next.js 14 (App Router)** و**TypeScript** و**Tailwind CSS**، ويعمل محلياً بصورة فورية بقاعدة بيانات SQL مدمجة (`node:sqlite` في المسار `./data/encyclopedia.db`) دون الحاجة إلى إعداد خادم خارجي مسبقاً، مع توفر مخطط كامل لـ **PostgreSQL / Supabase** في `supabase/migrations/0001_initial_schema.sql`.

```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تهيئة قاعدة البيانات والتحقق من المحتوى الموثق
npm run seed

# 3. تشغيل الاختبارات الآلية للوظائف الأساسية
npm test

# 4. تشغيل خادم التطوير المحلي
npm run dev
```

ثم افتح المتصفح على الرابط: `http://localhost:3000`

## 2. إضافة مفتاح Google Gemini API لتشغيل المساعد الذكي

يعمل الموقع ومحرك البحث والمقالات ولوحة الإدارة بصورة طبيعية كاملة حتى قبل إضافة مفتاح Gemini API. ولتفعيل التوليد الحواري الذكي في صفحة **«اسأل الموسوعة العُمانية»**:

### الطريقة الأولى: من لوحة الإدارة الآمنة (دون إعادة بناء الموقع)
1. افتح صفحة `/admin` وأنشئ حساب المدير الأول الخاص بك (لا توجد كلمة مرور ثابتة مسبقة).
2. انتقل إلى التبويب **«6. إعدادات Gemini API وسجل الأخطاء»**.
3. الصق مفتاح `GEMINI_API_KEY` الذي حصلت عليه من [Google AI Studio](https://aistudio.google.com/apikey).
4. اختر اسم النموذج (مثل `gemini-2.5-flash` أو `gemini-2.5-pro`) واضغط **حفظ** ثم **اختبار الاتصال بالنموذج الآن**.
5. يُشفّر المفتاح على الخادم بخوارزمية `AES-256-GCM` داخل `./data/secure-settings.json` ولا يُرسل أبداً إلى المتصفح.

### الطريقة الثانية: عبر متغيرات البيئة (`.env.local`)
انسخ ملف `.env.example` إلى `.env.local` وأضف المفتاح:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash
GEMINI_ENABLE_WEB_SEARCH=false
```
*(يبدأ المساعد بالعمل تلقائياً بمجرد قراءة المتغير على الخادم دون الحاجة إلى إعادة بناء الشيفرة).*
